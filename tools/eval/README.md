# tools/eval：训练前后对比用的一次性评估脚本

都是 `uv run python tools/eval/<名字>.py`，在项目根目录运行；检查点路径写在脚本顶部，换检查点要改脚本。

| 脚本 | 用途 |
|---|---|
| `compare.py [速度...]` | v4 / v5 / 混合策略在各速度下的速度、摔倒、触地、抬脚、外偏、左右差 |
| `wobble.py` | 各速度的横滚/俯仰 RMS、角速度、机身高度起伏、动作突变（无推力） |
| `transition.py` | 指令阶跃/斜坡/来回抖动时的摔倒、最大倾角、动作突变（带推力） |
| `jerk.py` | 高速时动作抖动与推力的关系（有无推力对比） |
| `terms2.py` | 各奖励项每步平均贡献（改奖励权重前先看量级，总和应当是正的） |

注意：这些是从会话临时目录拷过来的，没有经过整理；`posture.py` 才是正式的指标脚本。

- `terms3.py`：v5 在新低速奖励下的各项每步贡献（定权重量级）；`filmstrip.py`：渲染连续侧视+前视帧（`MUJOCO_GL=egl`），用来真实地看抬脚和晃动
